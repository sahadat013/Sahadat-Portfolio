## Upload to GitHub
Keep this structure exactly:

- `index.html`
- `style.css`
- `script.js`
- `README.md`
- `assets/`
  - `project-1.svg` … `project-6.svg`

In GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

No build step is required.
