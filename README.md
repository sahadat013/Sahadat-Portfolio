# Sahadat Hossain Portfolio — SVG Full Screen Version

This version uses the six original SVG artworks as the main full-screen portfolio sections.

## Structure

- `index.html`
- `style.css`
- `script.js`
- `assets/project-1.svg` ... `assets/project-6.svg`

## Sections

1. Home — project-1.svg
2. About — project-2.svg
3. Experience — project-3.svg
4. Skills — project-4.svg
5. Sample Work — project-5.svg
6. Contact — project-6.svg

The SVGs are not placed inside small cards. They are displayed large and centered, with scroll reveal, subtle floating animation, active navigation, smooth scrolling, mobile navigation, and a scroll progress indicator.

## GitHub Pages

Upload the files to the repository root, keeping the `assets` folder beside `index.html`. Then use Settings → Pages → Deploy from a branch → main → /(root).
