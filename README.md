# Sahadat Hossain Portfolio

A GitHub Pages-ready portfolio website built from the six supplied SVG artworks.

## Files
- `index.html` — complete page structure and portfolio content
- `style.css` — responsive design, hover effects and animations
- `script.js` — scroll reveal, animated skill bars, mobile menu and cursor glow
- `assets/project-1.svg` through `assets/project-6.svg` — original supplied SVG artwork

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will publish the site.

## Important
The SVG files are kept as assets rather than rewritten, so the original artwork remains intact. The animation is added by the HTML/CSS/JS around the SVGs.

Replace the `#` links in the social section of `index.html` with your real Facebook, Instagram, X and YouTube URLs.
